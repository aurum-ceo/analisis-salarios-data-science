# Análisis de salarios en Ciencia de Datos

Proyecto de análisis de datos sobre salarios y puestos relacionados con ciencia de datos e inteligencia artificial.

## Herramientas utilizadas

- Python
- pandas
- matplotlib
- CSV

## Análisis realizados

- Top 10 puestos por salario promedio
- Salario promedio por nivel de experiencia
- Salario promedio por modalidad de trabajo
- Panel automático de gráficos

## Datos

El proyecto usa un conjunto de datos público de salarios en ciencia de datos obtenido de Kaggle.

## Cómo ejecutar el proyecto

1. Instalar las dependencias:

```bash
python -m pip install pandas matplotlib
```

2. Ejecutar el programa:

```bash
python analisis_salarios.py
```

## Resultados

El programa guarda resúmenes en formato CSV y un panel de gráficos en la carpeta `resultados`.
